# Pencil 页面一比一还原设计

## 目标

在当前 Pencil 文件中建立一个 1920 × 831 的可编辑画面，尽可能贴近用户提供的 Miaoma vBuilder 截图。所有可见元素均使用 Pencil 原生节点构建，不把整张截图作为背景或不可编辑图片。

## 范围

- 还原顶部应用栏与 Data、Layout、Actions 导航。
- 还原左侧 Navigation、组件快捷入口和 Components 列表。
- 还原中央浏览器式预览容器、标题、提示条、表单控件、图例和关系图。
- 还原右侧页面工具条与 JSON 编辑器视图。
- 仅还原截图所示的静态状态，不实现交互、滚动、拖放或真实数据绑定。

## 构建方式

- 根画框固定为 1920 × 831，并开启裁切。
- 使用独立的结构画框划分顶部、左侧、中央和右侧区域。
- 文字、图标、控件、分隔线和装饰元素均保持为独立可编辑节点。
- 中央关系图使用圆形节点、文字标签和多色路径组成；优先匹配整体轮廓、密度、配色与视觉重心。
- 重复项目使用统一尺寸、字体和间距，必要时通过循环批量生成。

## 视觉基准

- 背景以白色和浅灰为主，强调色采用珊瑚红、蓝灰、青色和绿色。
- 字体优先使用 Inter，并用可用的中文字体回退。
- 细分隔线、轻阴影和圆角仅在截图中存在的区域使用。
- 关系图保持全元素可编辑，因此不承诺每条连线与原始数据完全一致，但整体视觉需在正常缩放下高度接近截图。

## 验收

- 画面尺寸和四大区域比例与截图一致。
- 主要文字内容、控件位置和颜色可辨识且接近原图。
- 所有可见内容均为可编辑节点，无整图铺底。
- 不存在异常重叠、容器塌陷或非预期裁切。
- 使用 Pencil 截图与参考图进行整体对照，并修正明显偏差。
