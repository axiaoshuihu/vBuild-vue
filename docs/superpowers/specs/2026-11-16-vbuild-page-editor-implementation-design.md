# VBuild Page Editor 编码设计

## 目标

根据 Pencil 文件中的 `VBuild Page Editor`，在 `apps/builder` 的 `/app/layout` 路由实现完整页面视觉。第一阶段以 1920 × 831 参考尺寸的高还原度为目标，保留现有路由，不实现编辑器业务交互。

## 实现边界

- 完成顶部品牌栏、Data/Layout/Actions 导航和发布按钮。
- 完成左侧 Navigation、组件快捷入口和 Components 列表。
- 完成中央浏览器式预览、站点页头、标题、提示条、表单控件、图例和关系图。
- 完成右侧页面工具栏、导出 JSON 行和语法高亮 JSON 视图。
- 保留现有 `/app/dataSource`、`/app/layout`、`/app/actions` 路由结构。
- 不实现拖放、表单提交、组件配置、JSON 双向同步或发布行为。

## 组件结构

### `AppNavigator.vue`

负责顶部 48 像素导航栏。沿用现有 Vue Router 选中态，调整品牌、导航间距、Layout 高亮和发布按钮，使其匹配 Pencil。

### `AppLeftPanel`

`AppLeftPanel.vue` 负责两列左侧区域的整体布局；`Navigation.vue` 展示页面列表。新增小型数据配置和展示组件，承载八个组件快捷入口以及下半部 Components 清单。

### `AppEditorRenderer.vue`

负责中央预览工作区。浏览器外框、地址栏、页面头部、标题、提示条和表单均使用语义化 HTML/CSS。关系图使用原生 SVG，并由静态节点与连线数据生成，避免引入图表依赖。

### `AppRightPanel.vue`

负责右侧 360 像素检查器。工具栏和 JSON 内容使用静态数据渲染；JSON 通过结构化 token 列表生成行号、折叠符号、缩进线与颜色，不使用可编辑代码编辑器依赖。

## 布局与样式

- 页面高度占满视口，顶部栏固定为 48 像素。
- 主内容使用横向 Flex：Navigation 320 像素、组件面板 300 像素、中央区域弹性填充、右侧 360 像素。
- 1920 × 831 为精准视觉基准；较窄窗口保留固定侧栏宽度，中央区域允许收缩和裁切。
- 复用 `variable.css` 中已有颜色和字号变量，并补充本页面需要的局部变量。
- 使用现有 `@icon-park/vue-next`；品牌火箭、关系图和无法精确匹配的装饰使用 CSS 或内联 SVG。
- 不使用远程图片或远程字体，避免离线显示差异。

## 数据流

- 页面列表、组件快捷入口、Components 清单、图例、关系图节点和 JSON 行均定义为只读静态配置。
- 顶部导航继续由 Vue Router 的当前路径计算选中态。
- 第一阶段组件间不共享可变编辑状态，也不新增 Pinia store。

## 异常与兼容处理

- SVG 关系图使用固定 `viewBox`，在中央容器中等比缩放并保持参考图的底部裁切。
- 长 JSON 内容由右侧容器裁切并提供滚动区域，不撑破页面。
- 页面宽度不足时中央预览优先收缩；固定侧栏不发生换行或堆叠。
- 图标缺失时使用尺寸一致的文本或 CSS 图形作为视觉回退。

## 验收

- `/app/layout` 在 1920 × 831 下与 Pencil 参考图的结构、间距、颜色和内容高度接近。
- 顶部导航路由仍可使用，Layout 在目标页面保持选中状态。
- 页面无异常横向堆叠、容器塌陷或非预期溢出。
- 关系图、JSON 行和所有主要文字均由代码生成，不使用整页截图背景。
- `pnpm --filter builder typecheck` 和 `pnpm --filter builder build` 通过；若项目现有配置导致基线失败，先记录并区分于本次变更。
- 使用浏览器截图与 Pencil 根画框进行视觉对照并修正明显偏差。
